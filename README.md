# Abhishek Kulkarni — Data Engineer Portfolio

A responsive, data-engineering-themed portfolio built with HTML and CSS.

## Files
- `index.html` — page structure and resume-based content
- `style.css` — responsive dark theme and visual styling

## Preview locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` and `style.css` to the repository root.
3. In repository Settings → Pages, select the main branch and root folder if prompted.
4. Visit `https://YOUR-USERNAME.github.io`.

## Personalize before publishing
- Replace the generic GitHub and LinkedIn labels in the navigation if you'd like to add your profile URLs.
- Add a resume download link or profile image if desired.
- Review the contact information before publishing publicly.
